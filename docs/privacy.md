# Privacy and copyright boundary

CineNihongo is a personal language-learning overlay. It sends audio only to a loopback-only process, retains audio only in a short memory buffer, stores only derived text locally, and includes no account, analytics, telemetry, or cloud service.

It does not download or redistribute media/subtitles, inspect protected media requests, or circumvent access controls. Users are responsible for using it only with content and services they are authorized to access.
